Aide

Dans « Mes recherches », cliquez sur « Nouvelle recherche », renseignez le sujet et les dates, puis choisissez la visibilité.

Ouvrez la saisie dans le même navigateur que celui de votre connexion. Les brouillons sont gardés dans le navigateur puis envoyés au retour du réseau.

Dans la fiche d'un dataset, choisissez « Importer Excel / CSV », associez les colonnes puis lancez l'import.

Vos recherches sont privées par défaut. Vous choisissez de les publier dans l'espace partagé.

Ouvrez « À valider », contrôlez la saisie puis validez-la ou rejetez-la avec un motif.
Glossaire
  • Dataset : jeu de données regroupant des événements d'observation.
  • Taxon : groupe d'organismes (espèce, genre, famille).
  • Métadonnées : propriétés d'une donnée (méthode, auteur, licence).
