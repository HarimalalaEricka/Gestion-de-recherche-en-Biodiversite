# Checklist quotidienne — Projet Nexora

À utiliser chaque jour, quelle que soit la fonctionnalité prévue dans le planning.

## Au début de la journée
- [ ] Relire les tâches prévues aujourd’hui.
- [ ] Définir le résultat à atteindre avant la fin de la journée.

## Pendant le développement
- [ ] Développer la fonctionnalité prévue.
- [ ] Tester régulièrement ce que je développe.
- [ ] Noter les problèmes rencontrés et les solutions essayées.
- [ ] Prendre des captures d’écran si une partie fonctionne déjà.

## À la fin de la journée
- [ ] Vérifier si le résultat attendu est atteint.
- [ ] Écrire dans le carnet de bord : travail réalisé, problèmes rencontrés et solutions.
- [ ] Faire un commit Git propre et pousser le code sur GitHub.
- [ ] Préparer la tâche du lendemain.
- [ ] Si une tâche n’est pas terminée, noter ce qu’il reste à faire et décaler la suite du planning.

## Checklist spéciale du vendredi
- [ ] Faire le point sur les fonctionnalités terminées pendant la semaine.
- [ ] Préparer une démonstration pour l’encadrant.
- [ ] Rédiger ou compléter la partie correspondante du mémoire.
- [ ] Mettre à jour le carnet de bord de la semaine.
- [ ] Vérifier que le code est sauvegardé sur GitHub.
- [ ] Définir les priorités de la semaine suivante.

## Règle importante
Ne considère pas une fonctionnalité comme terminée tant qu’elle n’a pas été testée et que son code n’est pas sauvegardé. Si tu bloques, note le problème, ce que tu as essayé et la prochaine action à effectuer.
